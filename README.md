My First 6 Web Development Projects
This repository documents six of my web development practice projects.
These projects helped me practise JavaScript fundamentals, work with
APIs, handle user interactions, and build simple web interfaces.
Projects

1. Weather App
A weather application that displays current weather conditions and
forecast information using a weather API.

Topics Practised: API integration, fetching weather data, displaying
dynamic content.

Technologies: HTML, CSS, JavaScript, Weather API
2. Joke Generator
A fun application that fetches and displays random jokes. Users can
click a button to get another joke.

Topics Practised: API requests, button click events, updating page
content dynamically.

Technologies: HTML, CSS, JavaScript, API
3. Counter App
A simple interactive counter that lets users increase, decrease, and
reset a number.

Topics Practised: JavaScript variables, functions, DOM manipulation,
event handling.

Technologies: HTML, CSS, JavaScript
4. Random User Generator
An application that fetches random user profiles, including details such
as names, profile images, email addresses, and locations.

Topics Practised: Working with APIs, handling data, and displaying
profile information dynamically.

Technologies: HTML, CSS, JavaScript, Random User API
5. Calculator
A calculator for performing basic arithmetic operations, including
addition, subtraction, multiplication, and division.

Topics Practised: JavaScript functions, DOM events, user input, and
arithmetic operations.

Technologies: HTML, CSS, JavaScript
6. Currency Converter Pro
A currency converter that supports multiple currencies and provides
currency conversion using exchange-rate data. It also includes a theme
toggle.

Topics Practised: API integration, data conversion, event handling,
and interface interaction.

Technologies: HTML, CSS, JavaScript, Bootstrap, Currency API
What I Learned
- Building web pages with HTML and CSS
- Using JavaScript to make pages interactive
- Handling button clicks and user input
- Manipulating the DOM to update page content
- Fetching and displaying data from APIs
- Organising and presenting small web development projects
Purpose
These projects represent my learning journey in frontend development. I
